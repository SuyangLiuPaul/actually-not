# word 板块日志（研究员：word）

立场：语言是活的；每条讲本义（有文献）、现用法、辞书处理。辞书主要查教育部《重编国语辞典修订本》（可抓取）；《现代汉语词典》无在线页面，仅 空穴来风 一条经《现代语文》2020 论文查到第5版/2002增补本的原文，其余不对现汉下断言。

## 采用（13）
- word-kongxue-laifeng 空穴来风：风赋/六臣注文选 + MOE + 宋奇霞论文（现汉 2002增补本 vs 第5版）。第7版未能直接核到。
- word-chaqiang-renyi 差强人意：后汉书吴汉传 + MOE + 朱庆之论文页面（仅摘要）。「差」训略/「强」训振奋 靠 MOE 释义与通行解释，较弱。
- word-shoudang-qichong 首当其冲：汉书五行志刘向「郑当其冲」 + MOE。四字成语最早出处未核。
- word-qiyue-liuhuo 七月流火：诗经七月 + 王力文章（经爱思想转载） + MOE 查无词条。现汉未核。
- word-bukan-zhilun 不刊之论：MOE「不刊」「不刊之论」 + 文心雕龙宗经。「误读成不予刊登」属推测。
- word-zhishou-kere 炙手可热：丽人行 + MOE。「今天指热门」为观察，无逐条报道。
- word-meilun-meihuan 美轮美奂：MOE（含礼记引文） + 维基文库页面确认存在该段。
- word-xiaoshi-liaoliao 小时了了：世说新语言语 + MOE。严格说是断章取义，非误用。
- word-wusuo-buyong-qiji 无所不用其极：大学 + MOE 两义项。贬义成因为推测。
- word-wen-bu-jiadian 文不加点：后汉书祢衡传 + MOE（释义为转述）。
- word-weiyan-weixing 危言危行：论语宪问 + MOE。
- word-doukou-nianhua 豆蔻年华：全唐诗卷523 + MOE。
- word-jiujia-bugui 久假不归：孟子尽心上 + MOE。严格说是词义转移，非误用。

## 放弃的候选
- 鼎力相助：MOE 的「鼎力」释义仅「大力」，例句「多亏你鼎力相助」；「敬辞只能用于他人」只在搜索摘要里见到、未找到辞书页面支持 → 弃。
- 万人空巷：MOE 释义「形容拥挤、热闹的盛况」，苏轼诗原文页面抓取失败（404/限额），未核 → 弃。
- 目无全牛：庄子原文与 MOE 已核，但「被误作目中无人」的流行度无依据 → 弃（可补）。
- 不足为训、登堂入室、不以为然、叹为观止、上下其手、始作俑者、不耻下问、有恃无恐、无出其右、沧海一粟、差点没：未及核实/无明确「误用+辞书」材料 → 未做。
