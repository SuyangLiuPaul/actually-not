# 其实不是

> 那些听起来天经地义、其实证据并不支持的生活常识。

早上不吃饭伤身、洗完头不吹干有湿气、骨头汤补钙、掰手指得关节炎——
这些说法讲了几十年，多数人从没想过要去查一查。

这个站点收了 **55 条**，每条写清楚四件事：

1. **你以为**——那句耳熟能详的话
2. **其实**——证据说了什么
3. **这个说法是怎么传开的**——通常比结论本身更有意思
4. **那到底该怎么做**

## 关于内容

- 每条都附了出处，多数来自系统综述、随机对照试验，或卫生机构的公开指南。
- 凡是「**证据不足以支持**」而不是「**已被推翻**」的，正文里都写明了区别。
- 有争议、有例外、有人群差异的地方尽量留了余地——把一个过度简化的说法换成
  另一个过度简化的说法，并没有变好。
- 按「信了会怎样」分了三档：`可能有害` / `白费功夫` / `无伤大雅`。
  55 条里有 18 条属于第一档。

**这不是医疗建议。** 这里讲的是人群层面的一般规律，落到具体的人身上未必适用。

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS v4，纯静态站点，无后端。
内容全部在 [`src/data/myths.ts`](src/data/myths.ts) 一个文件里。

## 想改内容？

发现哪条写错了、或者想加一条，欢迎提 issue 或 PR。
新增条目请照着 `src/data/myths.ts` 里的结构写，并**附上出处**——
最好是系统综述、随机对照试验，或卫生机构指南。
